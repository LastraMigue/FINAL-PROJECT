
# Presupuesto económico — Lanzamiento comercial de GameMaster AI

## 1. Objetivo del presupuesto

Se elabora una estimación económica para el lanzamiento de GameMaster AI como una plataforma SaaS comercial dirigida al público general.

## 2. Costes de desarrollo y puesta en marcha

### 2.1. Desarrollo y subcontrataciones

Para garantizar el correcto funcionamiento de la plataforma, se contempla la contratación de profesionales especializados en desarrollo web, inteligencia artificial, integración de sistemas y seguridad.

| Servicio contratado | Horas | Tarifa estimada | Coste |
|---|---:|---:|---:|
| Diseño UX/UI de la plataforma | 40 h | 40 €/h | 1.600 € |
| Desarrollo frontend con React | 140 h | 45 €/h | 6.300 € |
| Backend con Laravel, API y base de datos | 180 h | 50 €/h | 9.000 € |
| Sistema RAG y procesamiento de PDF | 80 h | 60 €/h | 4.800 € |
| Integración de reconocimiento y síntesis de voz | 60 h | 50 €/h | 3.000 € |
| Integración Lua y webhooks con Tabletop Simulator | 40 h | 50 €/h | 2.000 € |
| Integración de Stripe y suscripciones | 30 h | 50 €/h | 1.500 € |
| Pruebas y control de calidad | 60 h | 35 €/h | 2.100 € |
| Despliegue, infraestructura y configuración de seguridad | 40 h | 55 €/h | 2.200 € |
| Gestión y documentación del proyecto | 40 h | 45 €/h | 1.800 € |
| **Total** | **710 h** | | **34.300 €** |

## 3. Costes de funcionamiento durante el primer año

Una vez lanzada la plataforma, será necesario mantener los servidores, servicios externos y sistemas de inteligencia artificial.

Se estima un volumen inicial de entre 100 y 500 usuarios registrados.

| Servicio | Coste mensual | Coste anual |
|---|---:|---:|
| Servidor y alojamiento de la aplicación | 100 € | 1.200 € |
| Base de datos, almacenamiento PDF y copias de seguridad | 50 € | 600 € |
| Consumo de API de inteligencia artificial | 200 € | 2.400 € |
| Servicios de reconocimiento y generación de voz | 100 € | 1.200 € |
| Correo electrónico, monitorización y herramientas de mantenimiento | 30 € | 360 € |
| Mantenimiento técnico y actualizaciones | 400 € | 4.800 € |
| **Total** | **880 €** | **10.560 €** |

Estos importes son estimaciones y pueden aumentar según el número de usuarios, la duración de las partidas y el consumo de los servicios de IA y voz.

## 4. Resumen del presupuesto y contingencias

| Partida | Coste |
|---|---:|
| Desarrollo y subcontrataciones | 34.300 € |
| Equipamiento y licencias | 240 € |
| Servicios profesionales adicionales | 4.200 € |
| Funcionamiento durante el primer año | 10.560 € |
| **Subtotal** | **49.300 €** |
| Contingencias (12 %) | 5.916 € |
| **TOTAL ESTIMADO** | **55.216 €** |

Se aplica un 12 % de contingencia para cubrir posibles gastos imprevistos, como un incremento del consumo de IA, ampliaciones de servidores, incidencias técnicas o necesidades adicionales de seguridad.

## 5. Conclusión

La inversión estimada para lanzar GameMaster AI al público y mantener la plataforma durante su primer año asciende a **55.216 €**, incluyendo una reserva del 12 % para contingencias.

Este presupuesto contempla tanto el desarrollo profesional de las funcionalidades principales como los gastos necesarios para mantener el servicio operativo durante al menos 1 año.

La inversión podría variar dependiendo del crecimiento de usuarios, el consumo de las API y las necesidades de infraestructura.

Los importes son orientativos y están expresados sin IVA ya que en una factura real, no todas las partidas tienen necesariamente el mismo tratamiento fiscal y una empresa podría deducir el IVA soportado si cumple los requisitos correspondientes.
